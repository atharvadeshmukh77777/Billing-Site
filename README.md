# FreshMart Grocery Billing System

A web-based grocery shop billing system developed using HTML, CSS, and JavaScript.

## Features

- Customer information
- Product selection
- Shopping cart
- Quantity management
- Discount calculation
- GST calculation
- Payment options
- Invoice generation
- Print bill
- New bill creation
- Dark mode
- Billing dashboard

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

Open `project.html` in your web browser.
